# Краулер ссылок с обходом антибот-защиты (CloakBrowser)

## Подготовка (выполняется один раз)

1. **Установите Python 3.8+** с [python.org](https://python.org) и добавьте в PATH.

2. **Откройте командную строку** в папке с проектом и выполните:

```bash
python -m venv .venv
.venv\Scripts\activate
pip install cloakbrowser playwright
playwright install chromium
```

3. **Авторизуйтесь в CloakBrowser** (только один раз):

```bash
cloakbrowser login
```
➡️ Откроется браузер, войдите через GitHub и закройте вкладку.

4. **Создайте файл `urls.txt`** со списком URL (по одному на строку).

## 🔑 Подробнее про авторизацию в CloakBrowser

CloakBrowser требует лицензионный ключ для работы. Бесплатная версия позволяет **1 одновременную сессию** и выдаётся через GitHub-аккаунт. 
Ключ нужно получить **один раз**, после чего он сохраняется локально и используется при всех следующих запусках.

**Способы авторизации:**

1. **Интерактивная авторизация через GitHub (рекомендуется)**
   ```bash
   cloakbrowser login
   ```
   - Откроется браузер с сайтом cloakbrowser.dev.
   - Нажмите **«Login with GitHub»** и разрешите доступ.
   - После успешного входа ключ автоматически сохранится в папке `~/.cloakbrowser/`.
   - Закройте браузер и вернитесь в консоль — авторизация завершена.

2. **Ручная установка ключа** (если у вас уже есть ключ)
   ```bash
   # Через переменную окружения (временная настройка)
   set CLOAKBROWSER_LICENSE_KEY=cb_xxxxxxxx
   # Или создайте файл с ключом
   echo cb_xxxxxxxx > %USERPROFILE%\.cloakbrowser\license.key
   ```
   Ключ можно получить на сайте [cloakbrowser.dev/free](https://cloakbrowser.dev/free).

**Важно:**
- При первом запуске **автоматически скачивается** защищённый бинарник Chromium (~200 МБ).
- Лицензия кешируется локально на **24 часа** — повторный вход не требуется.
- Ключ работает для **всех проектов** на этом компьютере.

**Проверка авторизации:**
```bash
cloakbrowser --help
```
Если команда выполняется без ошибок — авторизация пройдена.

## Запуск

Дважды кликните по `run_crawler.bat` – появится меню:

- **1** – запуск с настройками по умолчанию (`urls.txt` → `href_urls/`)
- **2** – указать свой входной файл и папку для результатов
- **3** – открыть этот README
- **4** – выход

Или запустите из командной строки с аргументами:

```bash
run_crawler.bat -i my_urls.txt -o my_results
```

---

## Результаты

Все собранные ссылки сохраняются в папке `href_urls` (или указанной вами).  
Для каждого URL создаётся отдельный файл с именем, соответствующим пути (например, `apply_credit.txt`).  
Если включено сохранение удалённых ссылок, рядом будет файл с суффиксом `_removed`.

---

## Примечания

- Если папка уже содержит файлы, скрипт спросит, очистить ли её перед запуском.
- Для смены настроек (прокси, таймауты, фильтрация) редактируйте `config.py`.
- При ошибках проверьте, что выполнены все шаги подготовки.
